# Project Gallery

A website showcasing a collection of mini projects created using HTML, CSS, and JavaScript by [navneet12300](https://github.com/navneet12300).

## Overview

**Project Gallery** is a web application designed to display and organize various mini projects. Each project highlights creative use of HTML, CSS, and JavaScript, demonstrating front-end development skills, interactive web design techniques, and dynamic user experiences.

## Features

- Showcases multiple mini projects in one place
- Clean user interface
- Built with HTML, CSS, and JavaScript

## Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/navneet12300/Project-App.git
   ```
2. **Open the website**
   - Simply open the `index.html` file in your web browser.
   - No build steps or installation required.
